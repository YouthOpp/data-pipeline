# Fulbright Bulgaria

This standalone standard-library adapter collects 37 genuine awards, applicant tracks and actual training editions from the Bulgarian-American Commission for Educational Exchange. The primary source is [the commission’s research-grants page](https://www.fulbright.bg/en/research-grants-for-bulgarians/). The implementation was reviewed against 40 complete public HTML pages on 9 October 2026, including the six outgoing and four incoming menu routes, Other, Alumni, professional courses, linked NGO/journalist/MBA programmes, and the complete two-page conference listing.

The output includes the actual Fulbright-Schuman variants, four archived US graduate award variants, core versus Flex scholar benefits, separate institutional host and individual specialist/assistant roles, three alumni award types, four dated paid course editions, and three genuine historical International Seminar editions. Paid courses are training opportunities with tuition costs, not funded scholarships. The October/November2026 PMP edition expressly costs EUR960 including VAT; the separate September/October edition does not publish a fee, so that price is not transferred. Alumni presentations, existing-grantee orientation/enrichment, provider lists, award capacities and country/course-module clones are excluded. Current news cards were reviewed for new programme routes; no claim is made that every historical news article was crawled.

Run the single actual nonpublishing collection test from this folder:

```sh
python -B test_adapter.py
```

It retrieves the complete reviewed source, validates every actual record and prints the complete JSON collection to stdout. Validation results go to stderr. It does not write a collected-record file or publish. Capture and validate stdout in memory. A refusal, challenge, disallowed redirect, incomplete document, missing programme, changed material eligibility/benefit, changed canonical or new own programme/policy route fails the whole collection; no partial successful collection is emitted.

The runtime checks complete programme and FAQ modules, source navigation and rights evidence. On the home page only, the rotating arithmetic question in the ordinary public contact form is normalized after validating its unique question/input pair, exact surrounding form structure and matching decimal input attributes. No answer is computed and no form is submitted. Contact terms, all other text, programme routes and legal evidence remain guarded; changed or ambiguous question structure fails closed. Reviewed team/contact blocks, court alumnus testimonials, portrait/gallery presentation, trainer biographies and irrelevant scripts/closed WordPress optimization comments are excluded from material fact guards. Canonical exceptions are exact reviewed observations: the substantive Humphrey leaf incorrectly advertises the home canonical, FIS2019 has no canonical, and the second conference listing uses the first-page canonical. Those observations do not permit arbitrary new canonicals or redirects. Known normal redirects to the NGO, court and teacher programme pages are represented by their verified final public URLs.

Amounts distinguish monthly maintenance, total caps, conditional benefits and applicant costs. Capacity does not create separate opportunities. Citizenship is projected only from an express source requirement; affiliation, topic countries and the Bulgarian publisher do not prove nationality or venue. The journalist page’s Bulgarian-citizen banner conflicts with a broader twelve-country origin paragraph, so its eligible-country array remains empty while both conditions are retained. The ETA banner’s ambiguous dual-citizen wording is preserved. Specialist roster acceptance does not guarantee a funded match. Host applicants are institutions; individual beneficiary citizenship is not an institutional passport condition.

Actual full date-only application deadlines remain date-only; no midnight or timezone is invented. Closing-day status is unknown. Yearless/month-only deadlines remain null. Event dates, degree-proof dates, interview/nomination milestones and external university admission dates do not become application deadlines. Explicit closed/completed/fully-booked programme evidence is distinguished from an archived page without an actual closing date. Historical titles and evidence preserve past rounds and training editions. Source conflicts are retained, including stale open/ongoing banners, dated alumni rounds, course enrollment forms and conflicting generic MBA/graduate FAQ figures. Current programme benefits are never borrowed across variants.

Requests use the normal identifying YouthOpp user agent, TLS verification and inherited proxy. Starts are spaced by at least six seconds with at most ten starts in every rolling 60-second window, shared across publisher apex/www aliases, robots, endpoints, redirects, retries and concurrent local processes. Retry-After is respected, redirect hops and transient connection attempts are bounded, and refusals are fatal. Workflow publication is serialized with the repository’s other source publishers; separate machines must not run publisher requests concurrently.

Publisher robots disallows PDF requests. During fresh research, the supplemental Agile exam-information link redirected toward a disallowed resource and was stopped before requesting the destination. No PDF, alternate path, query trick or HTML bypass was used; the main course HTML already provides the required facts. The policy and actual programme HTML remain required. An initial research-helper HTML-end assertion failed without retaining that first response; its original cause is unknown. A subsequent complete response demonstrably ended in closed WordPress optimization comments. The conservative completion guard accepts that observed format and rejects missing body/html, trailing noncomment content and challenge titles. This was a helper-format correction, not evidence of an access refusal or a bypass.

The commission’s privacy policy was updated 16 March 2026 and concerns applicant data processing. It grants no open content licence. Records contain independently written English facts, attribution and original public URLs; no images, copied publisher prose, applicant data, grantee stories or contacts are republished.

Publication uses `DATA_SOURCE_TOKEN` with write access to `YouthOpps/data-source`. The workflow obtains a scoped GitHub App token and runs `adapter.py --publish` on main, on relevant merges, manual dispatch and the configured schedule. Data and metadata are committed together under `datas/bg-fulbright-bulgaria/`. The actual publication code validates existing and new data, preserves last-good data on failure, updates failure metadata only for an existing source, retries a sibling-source ref race without force and never overwrites newer changes to this source. Local actual test success alone does not certify production Actions or site delivery; those need separate maintainer and independent verification.
